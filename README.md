- **Dynamic Hero Section**: Auto-scrolling promotional carousel with responsive aspect-ratio scaling for desktop and mobile displays.

  - Live In-Play, Cricket, Soccer, Tennis fixtures with Back/Lay odds boxes and match details view.

- **Instant Wallet Operations**:
  - Deposit modal with UPI gateway integration.

  - Live Passbook statement and Active Bets tracker.

## 📦 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/abusazid46-tech/allbazi.git

# Navigate to project directory
cd allbazi

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the development server
npm start
```

Open your browser and navigate to:
```
http://localhost:3030
```
